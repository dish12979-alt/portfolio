# AI Coding 产品实践作品集

这是一个面向产品实习投递的脱敏项目作品集，展示我在“盾构隧道数字孪生与监测分析原型”中的产品化实践，以及基于真实复杂项目的 AI Coding 使用体验观察。

## 项目概览

本项目面向地铁盾构施工数字化管理、结构安全监测和工程展示场景，围绕三维空间对象、盾构时序数据、传感器监测、地层钻孔、环片运维和分析结果解释，构建一套可演示的数字孪生原型。

页面中的截图和后续演示视频均基于脱敏历史样例数据及模拟展示数据生成，不包含敏感原始数据、合作单位内部资料或未公开分析模块细节。项目源码暂不公开，可在面试中提供脱敏演示说明。

## 作品集内容

- 项目总览：系统目标、核心链路与脱敏说明
- 产品设计：复杂工程场景的用户、痛点与产品方案
- 系统模块：三维主场景、盾构监控、掘进状态模拟、时序回放、地层建模、环片运维与传感器监测
- AI Coding 观察：Claude Code / Codex 在复杂项目开发中的使用流程、真实痛点与产品思考
- 演示视频：用于展示系统主流程和核心交互，视频链接见作品集页面
